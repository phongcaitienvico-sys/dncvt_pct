Sao lưu = chép nguyên file Google Sheet vào thư mục Drive NCVT_backup (tự động mỗi đêm 23h, giữ 30 bản).
Import dữ liệu từ Google Sheet cũ (làm một lần khi bắt đầu dùng app):
  1. Trên Sheet cũ: Tệp → Tải xuống → Microsoft Excel (.xlsx), chép vào thư mục samples/.
  2. Chạy python scripts/import_sheet.py samples/QL_De_nghi_cap_vat_tu.xlsx --dry-run để xem báo cáo đối soát.
  3. Chạy lại không có --dry-run → được out/db_khoi_tao.xlsx và out/import_errors.xlsx.
  4. Tải db_khoi_tao.xlsx lên Google Drive → Mở bằng Google Trang tính → gắn Apps Script và chạy setup() (xem README).
